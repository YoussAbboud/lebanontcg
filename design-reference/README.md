# Design references

The three reference images for Cardpost's visual language were uploaded as
attachments with the build brief. This directory records them for
traceability; `DESIGN-NOTES.md` at the repo root documents the extracted
language and `src/styles/tokens.css` holds the resulting tokens.

| Ref | Source image | What it contributes |
| --- | --- | --- |
| R1 | "XNFT — Unique Collection of NFT Arts" dark marketplace hero | Dark surface stack, vivid green pill CTAs, uppercase spaced nav, stretched-caps display type, spectrum gradient emphasis, glassy overlay chips on cards, large-radius framed panels |
| R2 | "Cards for Marketplaces" Figma sheet (lime/gray product cards) | Chartreuse highlight color, product-card anatomy (image → uppercase micro-label → bold title → caption), dotted-grid field, gradient card fills |
| R3 | "Trading Card Case Mockups" (graded slabs) | Slab-label grade badge (light strip, red bar, heavy grade numeral, mono cert number), condensed uppercase, holo emphasis on dark |

If you re-add the original images, drop them in this directory as
`r1-xnft-hero.png`, `r2-marketplace-cards.png`, `r3-slab-mockups.png`.
