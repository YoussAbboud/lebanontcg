# Design references

`sleeved/` holds the **governing reference (R6)**: the owner-authored
Claude design component ("Sleeved") this app's UI is transcribed from —
`Sleeved.dc.html` plus its assets (including the animated flag-gif logo,
which the app imports directly from `src/assets/flag.gif`, and the
original build prompt). `DESIGN-NOTES.md` at the repo root documents the
extracted system and anti-drift rules; `src/styles/tokens.css` holds the
tokens.

Earlier rounds (R1 dark-NFT hero, R2 lime marketplace cards, R3 graded
slabs, R4 purple NVC hero, R5 flag-card gif) shaped previous iterations
and are retired; their images arrived as chat attachments and are
described in the git history of this file.
