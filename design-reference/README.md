# Design references

The reference images for LebanonTCG's visual language were uploaded as
attachments with the build brief and the follow-up design review. This
directory records them for traceability; `DESIGN-NOTES.md` at the repo
root documents the extracted language and `src/styles/tokens.css` holds
the resulting tokens.

| Ref | Source image | What it contributes |
| --- | --- | --- |
| R4 | "NVC — Discover and experience the world of digital assets" purple marketplace hero | **Governing reference (second review round):** violet gradient field + light rays, floating segmented pill nav, sentence-case hero with white→translucent gradient text, glass cards (avatar header, rounded media, coin + stat-pill price row), white pill CTAs, auto-scrolling card rail |
| R5 | Lebanese flag trading card (gold-bordered slab, animated gif) | Brand mark: recreated as inline SVG (`src/components/FlagLogo.tsx`) with a holo-shine sweep; flag red/green/gold as micro-accents |
| R1 | "XNFT — Unique Collection of NFT Arts" dark marketplace hero | Glass overlay chips, large-radius framed panels |
| R2 | "Cards for Marketplaces" Figma sheet (lime/gray product cards) | *(Retired as color direction after the review round; its greens/limes survive only in the condition ramp)* |
| R3 | "Trading Card Case Mockups" (graded slabs) | Slab-label grade badge (light strip, red bar, heavy grade numeral) |

If you re-add the original images, drop them in this directory as
`r1-xnft-hero.png`, `r2-marketplace-cards.png`, `r3-slab-mockups.png`,
`r4-nvc-purple-hero.png`, `r5-lebanon-flag-card.gif`.
